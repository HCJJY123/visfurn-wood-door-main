Project door procurement questions

What should a project door quotation include?

Separate the door leaf, frame, architraves, seals, hardware supply, machining, packing and freight. Give each opening a door mark, quantity, size reference, wall thickness, finish and handing.

Can wooden and WPC doors be combined in one project?

They can be reviewed in the same door schedule, with separate models and quantities for dry rooms, bathrooms and other exposure conditions. Confirm the complete door-set configuration for each location.

Are these photographs verified customer installations?

The library uses illustrative application imagery and planning examples. It is a procurement resource rather than a record of verified VISFURN deliveries. Customer references require project evidence and permission.

How should buyers plan container loading?

Use the final packed dimensions, weights, frame and hardware packages, pallet arrangement and required shipment groups. A leaf count alone does not establish container capacity.
