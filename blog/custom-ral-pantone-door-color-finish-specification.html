Interior door finish approval

RAL and Pantone Door Colours: A Project Finish Approval Guide

For importers, distributors and hotel or apartment contractors comparing painted, film-faced and wood-finish door packages.

Colour reference · Component scope · Sample releaseUpdated 28 October 2026

Direct answer

Use a RAL or Pantone code as a starting reference, then confirm the surface process, sheen, texture and components with an approved physical sample. Ask VISFURN to review feasibility for the selected model; a code or screen image does not establish availability or an exact match.

Request an interior door finish review ↗

First identify the surface you are ordering

A request for “the same grey on every door” leaves a purchasing decision unresolved. A painted wooden leaf, a decorative film on an interior door and a woodgrain surface may use different selection and approval routes. The WPC label identifies a construction category; it does not by itself define the final face finish.

Identify the offered model and surface process before choosing a code. For a painted proposal, ask whether the requested reference can be reviewed through a sample. For a film-faced proposal, ask for the available film or décor reference and an actual sample. Do not assume a film can be ordered in every paint colour. A woodgrain name also needs its own pattern and finish reference.

Use the interior door collection or WPC door collection to identify the intended product, then compare the painted and PVC-laminated finish routes. The quotation should confirm which route is offered for that configuration.

Send the complete colour reference, not a screenshot alone

State the reference system, full code and the physical reference used. Identify whether the target is a supplier sample, a colour-standard sample or an existing installed door. Preserve any suffix or system identifier on the source reference instead of shortening it to a familiar colour name.

RAL explains that digital colour images approximate its physical samples and that screen settings and software affect their appearance. Pantone likewise distinguishes colour systems developed for different material applications. These principles support a physical approval step; they do not establish a coating recipe or a VISFURN colour-matching certification.

If the architect has specified one system but the proposed supplier sample uses another, record that as a proposed substitution. Obtain a decision against the physical samples. An online conversion or similar-looking code is useful for discussion but should not silently replace the specified reference.

Approve the leaf, frame and trim together

List every visible component that needs coordination: both leaf faces, edges, grooves or mouldings, frame, jamb extensions and architraves where included. Confirm whether the same finish process is proposed on each component. Hardware finishes should have their own references rather than being described as matching the painted door.

Review sheen and texture as well as colour. “Matte”, “satin” and “gloss” can remain subjective descriptions unless linked to an accepted sample or an agreed specification. Ask how any required measurement will be assessed; this guide does not prescribe a universal gloss value or numerical colour-difference limit.

For adjacent openings, arrange the proposed component samples together under agreed review conditions, including relevant project lighting where practicable. A close-up photograph of one leaf does not show how the whole door-and-frame package will read in the corridor.

Use an approval record that answers specific questions

A small sample can narrow the finish direction, while a larger panel or representative door-and-frame mock-up can answer questions about profiles, edges and component coordination. Agree the sample type and its purpose before arranging it. Sample availability, charges, transport and timing require confirmation for the selected model.

  • Reference: record the requested code, source sample and proposed surface process.
  • Scope: identify the model, leaf faces, frame and trim represented by the sample.
  • Appearance: record sheen, texture, grain direction where relevant and review lighting.
  • Decision: identify the approved sample, date, reviewer and unresolved differences.
  • Release: link the accepted record to the current drawing and door-schedule revision.

Keep photographs as a record of the reviewed items, with a clear sample ID. Retain the physical control sample where practical. A messaging-app reply such as “looks good” is difficult to apply later if nobody can identify which sample or components it covered. The door sample approval checklist covers the wider configuration release.

Plan inspection and phased orders before production

Agree how the production finish will be compared with the approved reference, which components will be reviewed and how exceptions will be recorded. Separate colour acceptance from other checks such as dimensions, hardware preparation and packing. A finish review does not establish fire, acoustic, moisture or other performance.

If instrument readings are required, ask the responsible specialist to define the method, conditions, reporting and acceptance criteria for the actual finish. Do not insert an arbitrary tolerance into a purchase order or assume every supplier uses the same method. The pre-shipment inspection guide explains why video evidence also needs a defined scope.

For floor-by-floor delivery or a later extension, retain the approved reference and identify the original order and finish revision. Ask for a new feasibility and sample review before releasing a later batch. An earlier colour code is not a guarantee that changed materials, finishes or components will produce an identical appearance.

What to send for an interior door finish quotation

Send the product link or reference images, intended application, quantities by model or opening group, sizes or drawings, and destination country and port or delivery location. Include the project date and any standards or approval requirements. Mark unknown fields as pending so an early review is not confused with production approval.

For the finish, attach the full reference code or identified sample, preferred sheen and texture, leaf/frame/trim scope, and whether adjacent or existing doors must match. State whether you need a sample panel, representative assembly or another approval item. Ask the quotation to separate the proposed door package from any sample or special finish-review scope.
