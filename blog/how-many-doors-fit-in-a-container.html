Shipping & Container Planning

How Many Doors Fit in a 20ft or 40HQ Container?

Calculate packed CBM, check gross weight and define the door package before comparing container options.

There is no reliable doors-per-container count without the packed dimensions, gross weights and loading arrangement for the actual order. A door leaf, a leaf with separate frame cartons and a preassembled door set are different shipping units. Start with a package list, then have the forwarder or loading team check both container options. A volume calculation is an estimate, not a confirmed loading plan.

Start with what “one door” includes

Before comparing quotations for wooden, WPC or hotel doors, state whether the order includes leaves only, frames and architraves, hardware kits, or assembled sets. Record whether those parts share a package or ship separately. A carton count is not necessarily a door-set count.

Use the approved quantity by size and door mark. If dimensions still refer to a building opening rather than the finished leaf, resolve that distinction using the door size and measurement guide before requesting packing figures.

Calculate packed CBM without counting the same space twice

For each rectangular shipping package, multiply its external length, width and height in metres by the number of identical packages. Add the results for every package type:

Total packed CBM = sum of external length × width × height × package quantity.

Use the outside of the shipping carton or crate, not the bare door dimensions. If goods ship as complete pallets, use each loaded pallet’s outer dimensions, including its base and any overhang, instead of adding those pallet volumes to the cartons already inside them. List loose frame bundles and hardware cartons separately only when they are not inside the measured shipping unit.

Compare 20ft and 40HQ using a loading plan

Ask the carrier or forwarder for the specifications of the equipment being offered. Check internal dimensions, door opening dimensions and allowable cargo weight rather than treating the container’s name or nominal cubic capacity as usable door storage.

  1. Check package fit. Can each pallet or crate pass through the container opening in the permitted handling orientation?
  2. Check the layout. Agree the rows, layers, stacking limits and securing method with the packing and loading teams. Do not assume that extra height can be used if packages cannot be stacked.
  3. Check weight. Total the gross weights of the actual shipping units. Confirm whether pallets and protective materials are already included, and allow for additional securing material. Have the forwarder confirm applicable container and inland transport limits.
  4. Compare the shipment scope. Request like-for-like quotations covering the same pickup point, destination and handling responsibilities. A larger container is not automatically the lower-cost option for an incomplete load.

Do not apply a universal utilisation percentage or a fixed count based only on “MDF”, “WPC” or “solid wood”. Use the final package list and reviewed layout to establish the quantity that can be booked.

Mixed sizes, LCL and your own freight forwarder

For a mixed project order, list each size lot and its packages separately. Link leaves, frame bundles and hardware kits to the same door marks. Tell the loading team if a particular floor or phase needs to be unloaded first; see the packing label and room schedule guide.

For a smaller order, ask your forwarder to compare LCL and FCL using the same packed dimensions, gross weights and destination. Request the full scope of charges, including collection, consolidation, destination handling and onward delivery where applicable. Neither a small quantity nor a CBM total alone establishes the cheapest or available shipping option.

If you use a receiving warehouse in China, identify it separately from the final destination country and port. State who arranges pickup, who confirms warehouse acceptance, and who handles the export booking. A warehouse address is not proof that consolidation, freight or destination delivery is included in the door quotation.

What to send for a packing and quotation review

Send the following with your enquiry. If a field is not yet known, say so rather than estimating a supplier specification.

  • Product or reference link, intended use, and quantities by size or door mark.
  • Leaf-only or complete-set scope, including frame, architrave and hardware requirements.
  • Destination country and port, or the agreed receiving warehouse and final export destination.
  • Any required packing format, handling restrictions or phased delivery sequence.
  • Whether you use your own forwarder, and your requested delivery timing.

Ask for a revision-dated package list with external dimensions, package quantities, gross weights and packing scope. Request confirmation of loading feasibility before booking freight. Estimated packing figures should be distinguished from the final shipment packing list.

Start with the relevant wooden door systems, WPC doors or hotel door packages, then send your door quantities and destination for review. Packing and freight scope remain subject to written confirmation for the order.

Container planning questions

Can I use one standard CBM figure for every door?

No. Use the measured outer dimensions of the agreed shipping packages. Frames, hardware, protection and palletisation can change the space required even when leaf dimensions match.

Does a CBM calculation confirm how many doors fit?

No. It totals package volume but does not establish a workable arrangement or confirm weight, stacking, securing or handling limits. Those checks belong in the loading review.

Can a small order go by LCL?

Ask the forwarder to confirm acceptance, packing requirements and an itemised quote for the specific shipment. Compare the full shipment cost with alternatives rather than treating a particular door quantity as automatically suitable.

Are door frames and hardware included in the packing estimate?

Only if the estimate explicitly includes them. Match the package list to the quotation scope, including separately packed items, before comparing container options.
