What information should a door schedule contain for a project RFQ?

Prepare a project door schedule for quotation and production release: opening IDs, size basis, door-set scope, dated revisions, approvals and destination.

Buyer guideGEO / AI search

Quick answer

For a bulk project RFQ, give each opening a stable door mark and show quantity, size basis, wall and frame conditions, finish, handing, hardware preparation and destination. Put a revision number and issue date on the schedule. Before production, resolve changed or provisional lines and identify the approved release version in the order.

A door schedule is not just a quantity list. It is the document that tells the supplier how each opening should be built, finished, packed and delivered. If the schedule only shows door counts, the supplier still has to guess the frame scope, hardware preparation and installation context.

Why the schedule matters

For project buyers, the best schedule is the one that separates each opening by ID and makes the differences visible. That is especially important in apartments, hotels, hospitals and other repeated-opening projects where small differences create big installation problems.

Minimum fields to include

  • Opening ID
  • Quantity
  • Application or room type
  • Rough opening
  • Leaf size
  • Finished wall thickness
  • Jamb depth
  • Finish reference
  • Handing or swing direction
  • Frame and hardware requirements
  • Packing sequence
  • Destination port or site location

If the project uses mixed door types, keep each type in a separate line. Do not combine bathroom, corridor, service and guestroom openings into one undifferentiated block.

How to avoid quotation mistakes

The easiest way to reduce mistakes is to make the schedule readable before it is sent. Use one row per opening type, keep the units clear and attach drawings or marked-up plans when available. If the opening size and leaf size are both known, send both. If one is missing, state that clearly.

Separate the RFQ schedule from the production release

An RFQ may contain provisional openings so a buyer can compare scope and budget. A production release needs a controlled answer for every affected door type. Use the project's own approval terminology; a supplier quotation, a consultant review and an instruction to manufacture are different decisions. If an opening is still under design review, mark it pending rather than treating a price as permission to machine the leaf or frame.

The door submittal package guide covers the supporting drawings and approval record. This schedule guide focuses on transferring that decision into the supplier RFQ and order.

Use one door mark to connect the drawing, quote and carton

Keep a stable mark such as D-101 for each opening or repeated opening type. Record its room use, quantity, material route, dimensions with units, size basis, wall and jamb depth, handing, frame and trim, finish reference, glazing or louvre detail where applicable, and hardware preparation. Reference the drawing revision beside any field that can change. Separate a typical bedroom opening from a bathroom, service or other special condition, even if the visible finish is similar.

Illustrative example: D-101 is a repeated bedroom opening with its frame and lock preparation stated. D-102 looks similar in the plan but serves a humid utility room and has a different threshold decision. Quoting both as one undifferentiated line hides a real scope difference. These marks and conditions are examples, not VISFURN product specifications.

For dimensions, use the inch-to-millimetre schedule handoff and the clear-opening guide. Do not label a rough opening as a leaf size, or infer a required clear passage from a nominal leaf width.

When drawings change, send a delta rather than a silent replacement

Issue a new revision with its date and list the affected door marks. For each change, state the old and new value, the controlling drawing or site-survey reference, the reason, and whether the supplier should reprice, revise a sample, change hardware machining, alter packing labels or wait for a decision. Keep superseded versions accessible to the project team so the change can be traced.

Change to flagWhat to ask before release
Opening or wall depth changesDoes the leaf, frame profile, jamb depth or trim scope change?

A comment on a drawing is not a substitute for a coordinated new release. The responsible project team should identify which contract and approval documents govern the work; supplier review alone does not verify local code compliance or transfer design responsibility.

Send one usable package for a quotation review

  1. Attach the latest dated door schedule and mark superseded copies as such.
  2. Add plans or elevations for non-standard openings and state whether dimensions are surveyed or provisional.
  3. List quantity by door mark and, if relevant, delivery phase or floor.
  4. Define what is included: leaf, frame, trim, threshold, glazing, seals, hardware supply and machining.
  5. Reference the approved finish or sample ID, plus any project-specific standards or documents that must be reviewed for the actual proposed assembly.
  6. Give the destination, packaging sequence and project timing; ask for a written response to missing details before release.

The door schedule CSV is a starting format. It cannot replace drawings, surveys or project-specific approval records. Compare interior door systems and WPC door options against the same opening schedule. To start a scoped review, send the latest schedule, quantities and destination.
