Questions from Canada project buyers

What should Canadian multifamily buyers include in a door schedule?

Include the project location, opening ID, room type, quantity, rough opening or leaf dimensions, finished wall thickness, frame or jamb scope, finish, hardware preparation, destination and packing phase.

How should wall thickness and jamb depth be confirmed?

Confirm rough opening, finished wall thickness, frame depth, jamb width, architrave or casing scope, floor finish and wall finish against the project information. Project-specific confirmation is required before production information is finalized.

When should WPC be considered for moisture-prone areas?

Compare WPC, wooden and other interior door options against room use, moisture exposure, cleaning routine, finish intent, frame material, edge condition, hardware and the project documentation.

What documentation should an importer request before ordering?

Provide the project location, architectural drawings, door schedule, wall build-up, frame requirements, finish schedule, hardware schedule, required standards and any authority requirements for project review.

How should packing labels be organized for phased apartment delivery?

Identify room, opening and phase labels together with quantities, mixed-model grouping, protection requirements and destination details so the packing plan can be reviewed for the approved configuration.

Can a mixed project order include different room types and finishes?

A mixed project package can be reviewed by room type, door model, finish, frame scope, hardware preparation, quantities and packing labels. These details should be organized in the door schedule.

How are dimensions confirmed when drawings use imperial units?

Imperial drawings can be coordinated into production dimensions, but rough opening, leaf size, frame size, wall thickness and hardware positions must be confirmed against the project information rather than assumed from a simple conversion.

What should be finalized before container planning?

Confirm quantity, approved configuration, frame scope, finish grouping, packing protection, opening or room labels, destination and any staged delivery requirements before container planning is finalized.
