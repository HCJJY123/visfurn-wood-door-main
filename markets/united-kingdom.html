What information should a UK contractor provide for a project door quotation?

State whether the project is a new build or refurbishment, then share the available opening, door-set, finish, ironmongery and packing information. This lets the quotation review distinguish coordinated new openings from existing-building conditions.

  • Project type, new build or refurbishment, schedule and opening ID
  • Existing opening information where applicable, leaf size and quantity
  • Frame or lining scope, wall thickness and architrave or casing
  • Handing, finish, ironmongery and existing frame condition where relevant
  • Destination, packing or project phase and required documentation

Door Planning for UK Refurbishment and Existing Openings

For refurbishment or existing buildings, confirm existing opening width and height, finished opening condition, existing frame condition, whether the frame is retained or replaced, wall thickness, floor finish level, skirting or wall finish interface where relevant, architrave scope, handing and existing ironmongery to retain or replace. Site dimensions and existing-condition information should be supplied and confirmed by the buyer, contractor or project team.

What changes when a door project is a refurbishment rather than a new build?

Refurbishment inputs

Existing openings, retained frames, variable wall conditions, existing floor levels, replacement ironmongery and room-by-room verification.

New-build inputs

Coordinated drawings, scheduled openings, wall build-up, planned frames or linings, hardware schedule and phased project release.

Project review

The required quotation input differs by project condition; neither route should be assumed from a generic door description.

Questions from UK project buyers

What should a UK contractor include in a project door schedule?

Include the project type, whether it is new build or refurbishment, opening ID, room type, quantity, existing opening information where applicable, leaf size, frame or lining scope, wall thickness, architrave, handing, finish, ironmongery, packing phase and destination.

What measurements are needed for refurbishment door replacements?

Provide the existing opening width and height, finished opening condition, existing frame condition, wall thickness, floor finish level, relevant skirting or wall finish interface, handing and the site dimensions available from the buyer, contractor or project team.

How should existing frames and linings be reviewed before quotation?

Identify whether the frame is retained or replaced, its condition and dimensions, the lining and architrave scope, wall build-up, floor level and installation interface. Site dimensions and existing-condition information should be supplied and confirmed by the buyer, contractor or project team.

What ironmongery information should be supplied before machining?

Supply the ironmongery schedule, hinges, locks or latches, handles, closers or access control where applicable, door stops or seals where project-specified, handing, machining requirements and available templates or approved drawings.

Can hotel or apartment doors be packed by room or opening number?

A hotel or apartment package can be organised by room number, opening ID, door type, finish group, handing, ironmongery group and packing phase after the approved configuration is confirmed.

How should architrave and wall thickness be coordinated?

Confirm the door leaf, frame, lining, jamb depth, architrave or casing scope, wall build-up, finished wall thickness, floor level, opening condition and installation interface for the specific project.

What project documentation should be reviewed for fire or acoustic requirements?

Provide the project specification, drawings, schedules and any buyer-supplied fire, acoustic, security, accessibility, authority or consultant requirements for documentation review. These requirements are reviewed against supplied project information rather than assumed from the product.

What is different between quoting a new-build and refurbishment door package?

A refurbishment package needs existing opening, retained frame, variable wall condition, floor level and replacement ironmongery information. A new-build package usually relies on coordinated drawings, scheduled openings, planned frames or linings, hardware schedules and phased project release information.
