Questions from Australia project buyers

What should Australian builders include in a project door schedule?

Include the project type, opening ID, room or zone, quantity, door leaf or rough-opening information, finished wall thickness, frame or lining scope, handing, finish group, hardware preparation, packing phase, destination and available project documentation.

How should mixed finishes and room labels be handled for a container order?

Identify door types, finish groups, room or opening labels, quantities, protection needs and release phases in the approved project schedule so packing can be reviewed for the actual configuration.

What frame and lining details should be confirmed before production?

Confirm the door leaf, frame, lining, jamb depth, architrave where applicable, wall build-up, floor finish, handing and installation interface. Project-specific confirmation is required before final production information is approved.

Can a hotel and apartment project use one coordinated door schedule?

A combined package can be reviewed when the schedule separates apartment unit types, hotel room groups, commercial zones, door-set types, finishes, quantities, hardware preparation and packing phases.

What documentation should be checked for project-specific requirements?

Provide architectural drawings, the door and finish schedules, hardware schedule, frame or lining scope, project specification, required standards and authority requirements where applicable. These requirements must be supplied and confirmed by the buyer or project team.

How should long-distance shipment timing be planned?

Plan against the approved configuration, project quantity, packing protection, container planning, destination and required release sequence. Shipment timing and trade terms are confirmed against the actual order and destination.

Can buyers request sample or finish approval before bulk production?

Sample or finish approval can be discussed before bulk production. The approved finish reference, door-set scope and related project information should be confirmed before final production information is released.

How should hardware preparation be shown on drawings?

Show lock preparation, hinge positions, closer or access-control preparation where applicable, handing, hardware schedule references and machining information. Hardware preparation is reviewed against buyer-supplied schedules, templates and approved drawings.
