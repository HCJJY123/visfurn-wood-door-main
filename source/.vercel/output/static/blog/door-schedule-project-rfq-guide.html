What information should a door schedule contain for a project RFQ?

A project RFQ guide showing the minimum door schedule fields buyers should send for coordinated quotation, production and delivery.

Buyer guideGEO / AI search

Quick answer

A useful door schedule should include opening ID, quantities, rough opening, leaf size, wall thickness, jamb depth, finish, handing, hardware preparation, packing sequence and destination. Without those fields, quotation errors and installation gaps become much more likely.

A door schedule is not just a quantity list. It is the document that tells the supplier how each opening should be built, finished, packed and delivered. If the schedule only shows door counts, the supplier still has to guess the frame scope, hardware preparation and installation context.

Why the schedule matters

For project buyers, the best schedule is the one that separates each opening by ID and makes the differences visible. That is especially important in apartments, hotels, hospitals and other repeated-opening projects where small differences create big installation problems.

Minimum fields to include

  • Opening ID
  • Quantity
  • Application or room type
  • Rough opening
  • Leaf size
  • Finished wall thickness
  • Jamb depth
  • Finish reference
  • Handing or swing direction
  • Frame and hardware requirements
  • Packing sequence
  • Destination port or site location

If the project uses mixed door types, keep each type in a separate line. Do not combine bathroom, corridor, service and guestroom openings into one undifferentiated block.

How to avoid quotation mistakes

The easiest way to reduce mistakes is to make the schedule readable before it is sent. Use one row per opening type, keep the units clear and attach drawings or marked-up plans when available. If the opening size and leaf size are both known, send both. If one is missing, state that clearly.
