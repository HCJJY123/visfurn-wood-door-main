What should buyers verify when choosing a fire-rated steel door supplier?

A practical buyer guide for checking tested set scope, destination-market requirements, hardware, seals, wall condition and supporting documents before ordering fire-rated steel doors.

Buyer guideGEO / AI search

Quick answer

When choosing a fire-rated steel door supplier, buyers should verify the full tested door-and-frame scope, the required fire duration, the destination-market standard, the hardware set, seals, wall condition and supporting documents before quotation. A leaf-only quote is not enough to confirm compliance or installation fit.

A fire-rated steel door should always be reviewed as a complete opening set, not as a single leaf. That means the buyer should confirm the frame depth, hinge and lock preparation, closer or seal requirements, opening size and the wall condition where the set will be installed.

What to verify first

The supplier should explain what is included in the requested tested scope and which documents are available for the market you are buying into. If the project needs a specific approval path, that requirement should be written into the RFQ before pricing. This reduces the risk of quoting the wrong build and discovering the mismatch after production has started.

  • Opening size and frame depth
  • Fire duration and target-market standard
  • Lock, hinge, closer and seal preparation
  • Wall condition and installation substrate
  • Document or approval notes that affect quotation

What to send in the RFQ

Send the project schedule, opening marks, quantities, drawings, target destination and any approval notes. If the project has fire, security or access-control requirements, include them in the same package so the supplier can review the whole set together.

Opening size and quantityWhich openings need the same set
Wall thickness and frame depthWhether the frame can fit the installed wall
Required hardware setPreparation for hinges, lock and closer
