Slab, Prehung or Full Door Set? How to Spec a Container of Doors So Nothing Is Missing on Site

Compare door slab, prehung and complete door set configurations so frames, architraves and hardware are not missing at installation.

US / UK / Australia / BalkansPrepared for B2B door buyers

Direct Answer

A slab is the door leaf only. A prehung door normally includes the leaf, frame and hinges. A full door set adds the selected hardware, architraves, seals and other agreed components. The purchase order must name each included part and the reference opening dimensions.

What changes between a slab, prehung and full door set?

ConfigurationUsually includesBest fit
Door slabLeaf onlySites with local frames and hardware
Prehung doorLeaf, frame and hingesProjects needing a ready-hung assembly
Full door setLeaf, frame, architraves, hardware and agreed accessoriesTurnkey apartment, hotel or villa packages

Why do door schedules fail at the jamb?

The most common mismatch is confusing rough opening, leaf size, frame size and finished wall thickness. A buyer should provide the wall build-up, handing, frame profile, architrave width and adjustment range before the shop drawing is approved.

What hardware must be named?

  • Hinge quantity, size, material and finish
  • Lock body, lever handle, cylinder and strike plate
  • Door closer, seals, viewer, drop seal or threshold where required
  • Screw type and preparation template
  • Fire, acoustic, accessibility or corrosion requirements when applicable

How should a container order be frozen?

Use one approved door schedule, one production confirmation sheet and a marked-up sample for every distinct type. Group each size and hardware family into a lot so the packing list and site labels remain readable.

FAQ

Questions buyers usually ask

Is a slab cheaper than a complete door set?

The unit price is usually lower, but the installed project cost depends on local frames, hardware, labour and site coordination.

What is an adjustable wall frame?

It is a telescopic or adjustable jamb that accommodates a defined range of finished wall thicknesses. Confirm the actual range before production.

Should architraves be included in the quotation?

Yes, if the project needs a complete finish package. List the profile, material, length and packing method.

Can VISFURN supply hardware with the door set?

Hardware can be included when the specification, finish and compliance requirements are confirmed in the approved BOM.

What document prevents missing parts on site?

A signed door schedule and production confirmation sheet with a component-level BOM is the best control.

Buyer questions before ordering

A full door set is safer when the project needs matched frame, architrave, hinges, lock preparation, seals and packaging labels. It reduces missing accessory risk for hotels, apartments and multi-unit projects.

Include opening ID, room type, quantity, leaf size, rough opening if available, wall thickness, jamb width, handing, finish, fire or acoustic requirement, hardware prep and destination port.
