What should a steel fire-door enquiry include?

Specify the whole opening: door leaf, frame, hardware, seals and installation conditions. For house and apartment projects, the quotation should connect the required dimensions and appearance with the project’s performance and documentation requirements.

01 / Specification

Start with the door schedule.

Separate the rough opening from the door-leaf size. Add the wall thickness, handing and required finish so the quotation can define a complete, consistent scope.

Project setting

A clear brief for residential openings.

For a house or apartment entrance enquiry, tell us where the door will be installed and which project requirements it must meet.

  • House projects: identify internal, sheltered or exposed openings.
  • Apartment projects: include the opening schedule, handing and hardware list for each door mark.
  • Other locations: state any stairwell, escape-route, weather, smoke or security requirements separately for review.

Buyer questions

Before you request a quote.

Send the details you already have. Missing dimensions, hardware or documents can be identified during the specification review.

What information is needed to quote this steel fire door?

Send the project country, number of door sets, opening or leaf dimensions, wall thickness, handing, finish and hardware requirements. Include the required fire rating and standard, plus a door schedule or drawing where available.

Does this model have a fixed fire rating?

This page does not assign a universal fire rating. The proposed door leaf, frame, hardware, seals and installation conditions must be checked against the requested standard and the documents available for that configuration.

Can the door be specified for a house or apartment entrance?

House and apartment entrance enquiries can be reviewed. State whether the opening is internal, sheltered or exposed, and provide the project specification so the proposed configuration can be assessed for that location.

Can dimensions, finishes and hardware be changed?

Send the required dimensions, finish reference and hardware schedule. Available options must be confirmed for the selected configuration, particularly where the project calls for documented fire performance.

What are the price, minimum order and lead time?

Request a project quotation with quantities, dimensions and destination. Unit price, minimum order, production time and packing scope are confirmed with the proposed configuration; shipping time is stated separately.

Does a fire-door enquiry also cover security or smoke performance?

List each required performance separately. Do not assume that a fire-related product name or document also demonstrates burglary resistance, smoke control or acoustic performance.
