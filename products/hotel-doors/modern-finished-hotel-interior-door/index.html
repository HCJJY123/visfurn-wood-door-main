Buyer questions

Details to settle before ordering.

A useful enquiry can begin with the drawings and references you already have.

Which hotel openings should I include in the enquiry?

Identify the exact location of each door: within a suite, at a guestroom entrance or in another interior space. If an opening has fire, acoustic, moisture or access requirements, include those in the schedule so the proposed configuration can be reviewed.

Does finished mean that every component is included?

The supply scope must be stated in the quotation. Ask whether the offer covers a finished leaf only, the frame and trim, or the specified hardware as well. Agree the finish reference and any remaining site work before ordering.

Can this model be reviewed for an existing hotel frame?

Send the existing frame measurements, leaf size and thickness, handing, hinge positions and lock details. Add clear photographs of the opening. Compatibility is checked against the proposed door configuration before the order is finalized.

What should I provide for electronic-lock preparation?

Provide the exact lock model and its machining drawing, including backset, lock-body dimensions and fixing positions. Confirm whether the required preparation is available for this model and which hardware is included in the offer.

Is this door waterproof, fire-rated or acoustically rated?

This page does not claim a tested rating. Describe the exposure or performance your opening requires and request documentation for the proposed complete assembly. A surface finish, photograph or product title alone does not establish that performance.

How should a phased hotel order be organized?

Assign a door mark to each opening and group quantities by room type, floor and delivery phase. Keep the finish reference and hardware set linked to those marks so quotation, packing and site allocation use the same information.
