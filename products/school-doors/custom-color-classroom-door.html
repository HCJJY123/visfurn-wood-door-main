Buyer questions

Before you request a quote.

Use these answers to prepare a useful enquiry, even if your door schedule is still being developed.

Can I request a color for my classroom project?

Send a color code, a physical sample reference or your project finish schedule. The offered finish type and color match should be confirmed in the quotation; use a physical sample when an exact match matters.

What should I send for a school door quotation?

Include the number of openings, room names, opening or leaf dimensions, wall thickness, handing, finish reference, hardware requirements and destination. Identify the type of measurement so the frame and leaf can be reviewed together.

Can the door include a vision panel or finger protection?

Include the panel shape, glazing requirement or finger-protection detail in your enquiry. Availability and the exact configuration must be confirmed for the proposed door set; these features are not implied by the product name.

How are different classroom openings handled?

Use a room-by-room door schedule with a door mark for each opening. Separate changes in size, handing, finish and hardware so the quotation and packing labels can follow the same schedule.

Where can I find the material, price and lead time?

Request a technical offer for your selected configuration and order quantity. The offer should state leaf and frame construction, finish, included hardware, price, order quantity, production period and packing scope.
