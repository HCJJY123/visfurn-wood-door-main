Rough Opening vs Door Leaf Size

Confusing these two measurements can affect frame fit, clearances, jamb depth and installation planning.

Direct Answer

The rough opening is the construction opening, while the door leaf size is the physical panel; a quotation must keep both dimensions separate.

The two measurements

MeasurementMeaningUsed for
Rough openingFramed construction opening before final trimSite opening and installation planning
Door leafPhysical moving panelPanel production and clearances
FrameDoor-set structure around the leafJamb, hinges, stops and trim

What to label on a schedule

Write the unit beside every value and use separate columns for rough opening width/height, leaf width/height, frame size and finished wall thickness. If the drawing uses a nominal door size, note whether it is a leaf, frame or opening reference.

Before quotation

Send one representative opening with the full wall build-up and a second example where the size or handing changes. This helps the review distinguish a repeated type from a project exception.
