How to Specify Custom RAL / Pantone Door Colors and Finishes for a Project

How to send a RAL or Pantone reference, avoid batch color drift and confirm sample approval before a bulk custom-color door order.

Finish SpecificationCustom colour control

Quick answer

Specify a custom door colour with a named RAL or Pantone reference, the required sheen, a physical finish sample and an approved control sample so the factory can match the same finish direction across the production batch.

Why a colour name is not enough

Names such as charcoal grey, walnut black or warm white can mean different things across screens, paint systems and suppliers. A named RAL or Pantone reference gives the project a starting point, but the final finish should still be approved on the actual door construction and surface process.

Sample panels and full-door approval

Small painted panels are useful for narrowing a colour direction. A full-door sample remains important because profile depth, edge treatment, frame material and viewing angle can change how the finish appears. Confirm whether the same colour must apply to the leaf, jamb, architrave and accessory pieces.

Matte, satin and darker finishes

Sheen affects both appearance and inspection. Matte surfaces can show handling marks differently from satin or gloss surfaces, while dark colours can look warmer or cooler under different light. State the expected visual reference and the site environment so the approved sample represents the project decision.

How to avoid avoidable batch drift

  • Use one agreed reference for each finish code.
  • Approve the colour on the actual door construction rather than on screen only.
  • Keep a control sample or approved panel for production comparison.
  • Separate finish codes clearly in the door schedule and packing labels.
  • Confirm whether replacement or phased batches must match an earlier approved sample.
